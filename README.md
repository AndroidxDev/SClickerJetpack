# **Blur Lab**

### **Blur Lab** — приложение для тонкой настройки эффектов размытия в интерфейсе Android.
Позволяет управлять blur-эффектами, градиентным блюром и визуальными элементами UI в реальном времени.

✨ **Возможности**

•  Включение / отключение Gaussian Blur </br>
•  Gradient Blur (градиентное размытие)</br>
•   Управление совместимостью с Liquid / Glass UI</br>
•  Поддержка светлой и тёмной темы</br>
•  Динамические темы (Android 12+)</br>
•  Мгновенное применение настроек</br>
•  Минималистичный Material-интерфейс</br>

⚙️ **Настройки блюра**</br>

•  Blur Enable — основной переключатель размытия</br>
•  Gradient Blur — градиентный эффект поверх блюра</br>
•  Liquid Top Bar — стеклянная / жидкая панель (имеет приоритет над блюром)</br>
•  Если включён Liquid Top Bar, blur-эффекты автоматически отключаются во избежание конфликтов.</br>

🌓 **Темы**</br>

•  Default (следует системной)</br>
•  Light / Dark</br>
•  Dynamic Light / Dynamic Dark</br>
•  Цветовые акценты (Red, Yellow и др.)</br>

🛠 **Технически**</br>

•  Jetpack Compose</br>
•  Material 3</br>
•  Поддержка Android 12+</br>
•  Оптимизировано для производительности</br>

📦 **Назначение**</br>

•  Blur Lab предназначен для:</br>
•  кастомизации UI</br>
•  тестирования blur-эффектов</br>
•  визуальных экспериментов</br>

⚠️ **Примечание**</br>

Некоторые эффекты могут зависеть от:</br>

•  версии Android</br>
•  устройства</br>
•  графического драйвера</br>
•  системных ограничений</br>
